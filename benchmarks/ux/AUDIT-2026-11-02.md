# UX audit — 2026-11-02 (ux-auditor)

Proposes only; nothing in `src/`, `index.html` or `tests/` was changed.

**How it was seen.** The real app served from the working tree (`python3 -m http.server`, which
included other workers' uncommitted edits to `src/` on this date), Playwright + `/opt/pw-browsers/chromium`,
**one viewport: 1440×900, Turkish** (the brief asked for lean). Seeded in-page: one event, 12 round
tables × 10 (one `VIP01`), 60 guest records / 118 people (6 VIP/VVIP), 52 seated, 12 checked in,
2 No Show. Screenshots: `benchmarks/ux/audit-2026-11-02/<screen>-1440-tr.png` (all-events, command,
floor, guests, seating, live, reports, guest-dialog, f8-panel). Console: no app errors (only the
blocked CDN requests the run aborted on purpose).

**Measured on every screen:** visible elements carrying their own text, and how many render under
11.5 px: Seating **67 / 79**, Floor Plan **50 / 53**, Live 47 / 98, Guests 42 / 82, Command 30 / 62,
All Events 8 / 26. `src/styles.css` holds 202 declarations of 8–10.5 px, **525 hex literals + 88
rgba() literals** next to 1 648 `var(--…)` uses.

## Three theme proposals

Each `tokens.css` redefines **only existing custom properties** (no new names — checked against both
`:root` blocks) and is a drop-in loaded after `src/styles.css`. Each `index.html` is a static,
network-free mock of the real Home, Seating and Live layouts using only the tokens (with findings 4
and 12 applied, and the primary button token-driven as in finding 5). **Until finding 5 is done a
token file reaches only part of the app** — see each `shots/real-app-*.png`.

| id | Idea | Suits | Risk |
|---|---|---|---|
| `kagit` (Kâğıt) | Today's warm paper, sharpened: darker ink `#1d1810`, firmer lines, one interaction blue `#255f92`. | An owner who likes the hotel warmth but finds it washed-out; lowest risk, inside the constitution. | Closest to today — if the dislike is structure (findings 1–3, 5, 8), it will still feel "the same". |
| `kapi` (Kapı) | Door-first: white work surfaces, near-black text `#0e151d`, cool grey structure, saturated semantic colours, tighter radii; warmth only in VIP brass. | Live use in bright foyers, fastest scanning, highest contrast. | Leaves the constitution's warm paper (needs the owner's explicit yes); can drift toward generic SaaS grey. |
| `lacivert` (Lacivert) | Linen-grey surfaces, navy `#15213a` as ink **and** the one interaction colour, brass for VIP only; content stays light (no dark shell). | A premium hotel-house look for planning meetings with clients. | Navy text and navy selection are close: selection must be shown by fill/outline, never colour alone. |
