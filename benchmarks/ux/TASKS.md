Generated by `benchmarks/ux/make-tasks-md.mjs` from `tests/suites/ux-operator-tasks.test.mjs` (run `node tests/run.mjs ux-operator-tasks --all`). Do not edit numbers by hand.

- **Clicks** include picking a file in the system dialog (1) and clicking into a field before typing (1). **Keys** are characters typed plus named keys (Enter, F8, Esc); a date counts 8 digits.
- **Seconds** are wall-clock for the task including the app's own work (Assisted Detection, export), excluding the suite's screenshots/audits. Same-machine comparisons only.
- Each step was screenshotted and audited: horizontal page scroll, text cut off (overflow hidden, no ellipsis), text spilling out of its box, text < 11px outside the plan drawing. After each task one Tab checks that keyboard focus is visible. Native browser dialogs and console errors are counted per pass.
